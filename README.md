# 2026 – 2027 年度計畫

互動式年度計畫追蹤頁 — 單檔 HTML，無相依套件、無 build step，打開 `index.html` 就能跑。

## 🔗 線上網址

https://hsiangyilu.github.io/yearplan/

（GitHub Pages，從 `main` 分支根目錄自動建置）

## 功能

- **整體進度條** — 統計所有任務完成比例
- **時間分佈總覽** — 2026/4 ～ 2027/3 的甘特圖式網格（求職、Vibe Coding、商用英文、駕照、按摩等主線，加上健康 🦷🏥 與旅行 ✈️ 標記）
- **每月可展開卡片** — 點開看當月待辦、勾選打勾
- **進度自動儲存** — 用瀏覽器 `localStorage`（key: `plan2026v2`）

> ⚠️ 進度是「分裝置」的：存在各瀏覽器本機，電腦與手機不會互相同步。

## 計畫主軸

UX 設計師轉職 Web3 Designer 的時間軸。求職進度溫和後延，完成目標移至 **2027 上半年**：

| 階段 | 時間 |
|---|---|
| 素材準備（作品集 / Vibe Coding） | 2026 4–5 月 |
| 作品集收尾＋上線 | 2026 6–8 月 |
| 面試訓練 | 2026 8–9 月 |
| 第一波投遞（10 月中出國，錯開） | 2026 10–11 月 |
| 主力面試（1 月過年前淡季，隨機應變） | 2026 12 月 ～ 2027 3 月 |
| 收 offer 談判 → 到職 | 2027 春 → 上半年 |

## 更新流程

改完 `index.html` → commit → push 到 `main`，GitHub Pages 約 1–2 分鐘自動重建，網址不變。
